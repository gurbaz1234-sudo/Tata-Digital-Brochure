TATA SIERRA.ev Digital Brochure - web version (full quality)

HOW TO PUBLISH ON GITHUB PAGES (free)
1. github.com -> New repository (e.g. "sierra-ev-brochure"), Public.
2. Add file -> Upload files -> drag ALL 12 files from this folder in (no sub-folders). Commit changes.
3. Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
4. After 1-2 minutes your link appears: https://YOUR-USERNAME.github.io/sierra-ev-brochure/

Share that link on WhatsApp. It opens in Chrome / Safari with the full experience, and after the first
open the whole brochure is stored on the phone, so it works offline (it can also be added to the home screen).

FILES
index.html            the brochure
hero.mp4, design.mp4, interior.mp4, summon.mp4, autopark.mp4, slope.mp4   the six full-quality films

To update later: upload the new files over the old ones. Phones pick up the new version on their next online open.
